## 1. 已定

### 1.1 点的「已完成」：删掉就好

纠偏 `complete` 继续把事项从当天拿掉，不另做「已完成」栏。记忆插件会记住已经发生的事，构画不管历史归档。

配套：

- 删掉前把标题记进「最近改动」（见 2.1），方便反悔。
- 锁定项默认不 complete，除非反馈点名。
- 推迟仍是挪走或进未来，不是完成。
- 不在点菜单里再做第三种锁。

### 1.2 面重新生成：三种都要

刷新勾了面时，可选：

| 模式 | 做什么 | 不做什么 |
|---|---|---|
| 全部 | 整份替换 | 不自动跑 |
| 当前节点 | 只改游标这一条 | 不改更早节点 |
| 续写 | 保留已有，只往后追加 | 不回头改旧节点 |

默认「当前节点」。自动判定 / 自动对齐**绝不**整份重写面。冷知识、面也不走点/线对齐补丁。

### 1.3 本轮拍

保持现状。侧栏单独一页，可刷新。新一楼旧拍自然过期，不必标「已用」。

### 1.4 间引导落地后要能反悔

不弹 toast。写入结果只出现在插件里的「最近改动」：

- 列出**改了哪几条**（点用标题，线用名称，面用节点标题）。
- 提供撤回：用落地前快照一次性还原本次写入的模块，不和后来的手动编辑混算。
- 没勾「按草案改」的模块不动，也不出现在清单里。

### 1.5 对齐按楼数，线推进按日期变

不要把对齐拆成「只改点、线交给日期」。点是未来日程，线是平行事件，**走偏都要尽快改**，不能等换日。

分工：

| | 跟什么 | 管什么 |
|---|---|---|
| 点/线按正文对齐 | 每 N 条 AI 楼 | 补丁：点删除/推迟/改描述；**线收束/暂缓/改描述**。不符合剧情的平行事件在这里处理。 |
| 线自动推进 | 故事日期变了 | 未锁线往前演化（阶段、下一步），不是纠偏。 |

新装或打开自动推进时，**默认时间制**。回合制还留着，但不推荐和楼数对齐叠用。

同一楼两边都到期（换日刚好也该对齐）：

- **本楼先对齐，推进欠一楼，下一楼补上。** 推进不是取消。
- 时旅占闸两边都不跑。面自动只推游标。

不符合剧情的线：对齐把它收束、暂缓或改掉。推进只负责「日子过了，还成立的线往前走」。锁定线两边都默认不动。

### 1.6 冷知识：少自动、贴近文、住在线页

现状：默认关；开了以后跟线生成/推进顺手抽 1～2 条随机主题，塞进楼内线块。容易空泛、重复，还多一次 API。

下一轮按这个收：

- **默认仍关。** 不当第三条后台节奏。
- **不要再绑死「每次线推进都抽」。** 要自动的话自带更慢间隔（建议默认 6 条 AI 楼或只在手动刷新/线页点＋），并和 1.5 同一套错开：对齐 → 推进 → 冷知识，同楼最多跑一件。
- **取材改近文边角。** 优先「正文刚带过、但没讲清的风物/规矩/来历」，不要随机百科。主题可钉在本聊天（例如只挖地点），不要每轮洗牌。
- **家在线的冷知识页。** 楼内块默认不展示或只留一句「补了一条，去线页看」；换一条仍用手点。
- **去重维持：** 避开最近已写、锁定保留、未锁按条数清理。新条目进「最近改动」，不 toast。
- **不注入主楼 AI，不对齐补丁。** 写错了只勾刷新条的冷知识。

## 2. 本轮要做

### 2.1 后台任务安静但可查

通知保持 lite：后台改账不必每条弹窗。另做一条「最近改动」：

- 谁改的：自动对齐 / 线推进 / 面判定 / 间引导 / 手动刷新
- 改了什么：模块 + 条目标题 + 操作（完成/推迟/改描述/游标前进…）
- 只留本聊天最近若干条
- **入口放在插件里**（建议侧栏顶或刷新条旁一枚「改动」），点开看明细和撤回。间引导落地也只写这里，不 toast

失败才 toast。成功默认不吵。

### 2.2 设置页按三句话收

现在推进、注入、对齐名词叠在一起。收成：

1. **跟剧情走**（可选，默认多半关）：点/线按楼对齐、线按日期推进、面游标判定、日期兜底
2. **塞给主楼 AI**（改模型行为，另开）：总闸 + 线 / 面 / 刻度注入
3. **我自己点**：刷新条、本轮拍、间引导；不另做总开关

每项一行人话，少写「潜伏」「游标」而不解释。不删能力，只改分组和措辞。
