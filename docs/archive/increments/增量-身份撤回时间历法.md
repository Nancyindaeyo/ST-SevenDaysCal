# 构画增量：稳定 id、按条撤回、年/时辰、历法与刻度

更新：2026-09-11。按作者确认：1/2/3/4 同一轮落地。不拆 `index.js`（拆法另见 `增量-index拆分.md`）。不在浏览器里调试。

## 1. 点 / 线稳定 id

不改 `Event:` / `Line:` 管道字段，也不做 schema v2。

本地写入时，在现有 widget 里加可选元数据行（和 `Adult:` / `Cue:` 一样）：

```
Event: main|体检|…|false
Id: POINT-xxxx

Line: 调查|延展|…|false|false
Desc: …
Next: …
Id: LINE-xxxx
```

- 生成提示词不教模型写 `Id:`。AI 新稿没有 id。
- 第一次本地序列化（锁定、编辑、对齐补丁、换日滚点）给缺 id 的条目补上。
- 匹配：两边都有 id 就认 id；否则仍认标题 / 名称。
- 「改」跳转带 `ref`；DOM 写 `data-jump-ref`。

锁定回并时，旧锁定项的 id 跟到新稿上，标题改了也对得上。

## 2. 按条撤回

整模块快照仍是快路径：当前 raw 还等于落地后 raw，就整份还原。

若你后来只手改了其中几条：

- 按 id（没有 id 则标题）看「落地后那条」现在还在不在、内容变没变
- 没再动过的，从落地前快照里单条还原
- 已经手改过的，不动
- 卡片上每条可以单独「撤回这条」；整卡撤回等于撤回所有还能还原的

做不到数据库事务。面 / 冷知识仍整份快照（冷知识本来就有 id）。

## 3. 年 / 时辰（60/95）

锚点已能存可选 `year`。这一轮补齐读写，**不把点 StartDate 的假年 2024 当成故事年**。

- 完整时间戳或正文/柏宝书有公历年 → 写进日期锚
- 轴 ±1 天：有年就用真实加日（可跨年）；没年仍走年环
- 时辰：完整 SDC 的 `HH:MM` 存到锚点上，给轴/今头显示；刻度、点格子、推进仍按「天」

不做：子日对齐节拍、距今几小时、刻度按小时判定。

## 4. 历法可确认写入、刻度跨周期

- `commitCalendarDesc`：历法描述 + 节日两条走 `writeStoreConfirmed`，同一 chatId 闸。第二条失败则尽量把第一条补偿回去。不是 ACID。
- 刻度「滚周期」：今天/到期有年时，用 `addCalendarDays` 写出带年的下一次到期；没有年则 unknown，不拿年环去猜过期。一次性事项本来就要求两边都有年。
