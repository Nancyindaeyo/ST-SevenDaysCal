# 构画增量：开局排队、换日滚点、入口收束、柏宝书配料

更新：2026-09-10。按作者确认落地。不在浏览器里调试，作者自行验收。

记忆源已开柏宝书。楼内框保持折叠；「改」角标保持现状。

## 1. 开局：排队生成账本

空账（这串聊天还没有面、点、线）时，空页改成一颗「生成账本」。

顺序，一次一项 API：

1. 面
2. 点
3. 线
4. 轴（还没有节日才跑）
5. 冷知识（总开关开着且还是空的才跑）

进度写在空页上。失败则停在该项，前面已写入的保留，可「重试这一项」或中止。刻度不进开局。

已有任意一本点/线/面时，不再出现这颗按钮，避免洗掉旧账。单页「生成点 / 生成线 / 生成面」仍留给补缺和失败重试。

## 2. 换日：格子前移，不调 API

`StartDate` 跟着「今天」走。4.14 过了，4.15 变成今天。

- 旧今天未锁事项 → 完成并删除，记进「改」，可撤回
- 锁定事项滚出窗口 → 进「未来」
- 明天/后天整格前移，天气跟着走
- 往回拨日期（轴 −1 天、时旅）不在这里猜格子；时旅仍走按目标日重排

挂在 `runAnchorAftermath`。时旅若已把 StartDate 钉到目标日，delta 为 0，不会再挪一次。

## 3. 入口三个动词

| 动词 | 谁用 | 行为 |
|---|---|---|
| 生成账本 | 空账空页 | 排队 |
| 刷新账本 | 页头圆形刷新 | 打开折叠并勾当前模块；对齐或重做仍要勾选。面整份替换必须在条里选「全部替换」 |
| 推进 | 线页 / 楼内线块 | 不变 |

楼内刷新线、间卡片、引导草案不动。

## 4. 冷知识错开

对齐或推进占住的楼，冷知识若到期则记一笔欠账，下一空楼补抽。`stagger.deferDashed` / `consumeDashed` 接到生产。

## 5. 柏宝书配料

不把计划对拷成点。生成点/线/面/间时，在记忆块旁加一段只读配料：眼下时间地点、进行中计划/悬念、在场 NPC。历史正文仍走已开的 `getInjectedHistory` / `getHistory`。

## 6. 不做

年/时辰、按条撤回、稳定 id、历法可确认写入、拆 `index.js`、改楼内框默认、改漏戳救援、本轮拍入口。
